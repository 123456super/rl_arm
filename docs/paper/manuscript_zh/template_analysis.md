# 投稿模板分析

`docs/Templates/Conference-LaTeX-template_10-17-19/conference_101719.tex` 使用 `IEEEtran` 的 `conference` 选项，核心版式为 Letter 纸张、双栏排版。模板要求保留标准标题、作者、摘要、关键词、分节、图表、公式和参考文献结构，不应修改页边距、栏宽和字号。

对当前论文最重要的适配点如下：

1. 标题不使用副标题；作者和通讯作者信息仍是占位符，投稿前必须替换。
2. 摘要和关键词使用模板环境；关键词控制在 3--10 个。当前初稿使用 6 个关键词。
3. 公式使用编号的 `equation` 环境；图题放在图下方，表题放在表上方，图内避免中文字符。
4. 参考文献采用 IEEE 编号制，正文必须通过 `\cite{}` 引用；初稿已放入 SAC、课程学习、HER、经验回放和机械臂位姿控制相关文献，并保留 DOI 或公开链接。
5. 会议须知要求最终稿控制在 4--20 页，并检查作者信息、图像分辨率、表格可编辑性和参考文献完整性。当前环境已经安装 XeLaTeX 和中文宏包，初稿可编译生成 4 页 PDF；最终仍需替换作者信息、补入图表并检查双栏断页。

中文正文放在 `main.tex`，本目录额外复制了模板所需的 `IEEEtran.cls`，便于独立编译。实验数据、作者信息和图表仍按论文实验协议补入。

论文中的关键点位姿表示已注明来源于 `全身末端执行器位姿跟踪`（Portela 等，arXiv:2409.16048v2）：三关键点立方体表达作为已有几何基础，本文的研究增量限定为固定基座随机位姿到达中的 Jacobian 局部方向、联合优化信号和精度边界数据机制。

# 面向动态障碍物的连杆级预测风险约束控制与 Residual 学习

## 1. 论文主题

目标是面向**单个动态障碍物**，先用连杆级预测风险和确定性安全基座保证“走得对”，再让 RL 只学 residual，补足局部收敛与绕障能力。

一句话概括：
**基座负责方向，Residual 负责修正。**

## 2. 实验路线

```text
阶段 1：无障碍 reachability
  → 先验证纯 actor 的到达能力和基础收敛

阶段 2：静态障碍物
  → 再验证绕障与终端收敛

阶段 3：单个动态障碍物
  → 最后加入预测风险、deterministic base 和 residual 学习
```

## 3. 当前进展

- 阶段 1 已完成并冻结。
- 当前无障碍基线可写为：**固定 IK 可达子集 100% 到达，full set 97.0%**。
- 这说明纯 actor 的基础到达链路已经恢复，能作为后续避障实验的起点。
- 静态障碍物阶段尚未彻底解决，当前仍保留为未完成问题，不能写成最终成功。

## 4. 当前代码对应的研究方向

- 不是单纯纯 RL。
- 不是只靠安全过滤器。
- 也不是完整动态避障主结果。

更准确地说，当前代码是在走：
**无障碍 reachability 基线 → 静态障碍物迁移 → 单动态障碍物 residual 避障**

## 5. 预期论文结构

1. 无障碍 reachability 基线
2. 静态障碍物下的终端收敛与绕障
3. 动态障碍物下的预测风险约束控制
4. residual 学习对局部失败的修正作用

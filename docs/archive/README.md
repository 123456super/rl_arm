## 归档规则

- 归档材料只用于历史复核和基线对照，不再作为当前实验指令。
- 小型文档、结果摘要和诊断报告保存实体副本；checkpoint、replay、CSV 和 trace 等大文件保留在原路径并由资产清单索引。
- 不移动原始 `outputs/`，以免破坏配置、脚本和摘要中的复现路径。
- 历史记录与后续复跑必须分开标注，不能把不同批次的数据合并成一次实验。

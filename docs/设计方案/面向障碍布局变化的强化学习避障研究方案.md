# 面向障碍布局变化的机械臂强化学习避障方法研究

> 根据截至 2026-11-11 的实际代码、训练配置和确定性评估结果更新。

## 1. 研究问题

针对机械臂强化学习策略在固定障碍布局中有效、但在障碍物数量、形状、位置和运动状态改变后容易碰撞、停滞或遗忘到达能力的问题，研究一种面向障碍布局变化的机械臂强化学习避障方法。

任务统一定义为：机械臂从固定安全初始构型出发，在目标位置随机、目标姿态相对基座固定的条件下，避开障碍物、自碰撞和安装平面，最终满足位置与姿态精度要求。测试时冻结策略参数，不针对新布局重新训练。

## 2. 统一任务和控制设定

### 2.1 目标与初始状态

\[
p_g\sim P_{\mathrm{target}}\bigl(\mathcal W(R_0)\bigr),
\qquad R_g=R_0.
\]

- 固定初始关节角为 \([45,-90,90,0,45,-90]^\circ\)；
- 固定目标姿态欧拉角为 `[0, 1.57, 1.57]` rad；
- 目标位置在 UR5 可达工作空间内随机采样，并通过 IK/FK、关节限位、自碰撞和目标端安全间隙检查；
- 运动过程允许末端姿态变化，最终同时评价位置和姿态误差。

### 2.2 动作与真机导向约束

策略输出 6 维关节角度增量。最终动作由真机一致的关节运动控制器执行：

| 参数 | 最新设定 |
| --- | ---: |
| PPO 决策周期 | 0.4 s（2.5 Hz） |
| PyBullet 物理频率 | 240 Hz |
| 每个策略动作的物理子步 | 96 |
| 关节速度上限 | 10 deg/s（0.17453 rad/s） |
| 关节加速度上限 | 20 deg/s²（0.34907 rad/s²） |
| 回合长度 | 150 个决策步（60 s） |
| 真机底层控制频率参考 | 125 Hz |

当前只显式限制关节速度和关节加速度，不再单独限制 TCP 线速度。碰撞不终止回合，使策略能学习从危险状态恢复，但每一步接触都给予明确惩罚。

## 3. 总体方法

### 3.1 S0 冻结到达 Base

S0 使用 PPO 学习无障碍物条件下的随机位置到达策略。基础观测为 34 维，包含关节角、末端位姿、目标位姿、紧凑误差、位置/姿态误差向量和归一化关节速度。

正式 Base 模型为：

`outputs/base_models/s0_base_cb31_10deg_125hz_horizon150/s0_base.pt`

在 400 个确定性评估回合中，其平均最佳位置误差为 `1.71 mm`，平均最终位置误差为 `2.31 mm`，平均最终姿态误差为 `0.00376 rad`，无碰撞且曾满足 `5 mm / 0.05 rad` 的比例为 `98.75%`。该 Base 使用 10 deg/s 关节速度、20 deg/s² 关节加速度、0.4 s 决策周期和 125 Hz 底层控制调度，不单独限制 TCP 线速度。S1/S2 中冻结 Base Actor，避免后续避障训练破坏已有到达能力。

### 3.2 可变数量障碍物集合编码

障碍物在几何层统一表示为 OBB。对第 \(i\) 个障碍物构造 9 维特征：

\[
o_i=[d_{i,1},d_{i,2},\ldots,d_{i,6},u_{i,x},u_{i,y},u_{i,z}],
\]

其中 \(d_{i,1}\sim d_{i,6}\) 是该 OBB 到 UR5 六个碰撞胶囊的有符号最小间隙，\(u_i\) 是最近胶囊指向 OBB 最近表面的单位方向。OBB 中心、尺寸、姿态和速度不直接输入策略，其影响已体现在间隙和方向中。

系统最多接收 8 个障碍物，使用 mask 处理变长集合。每个障碍物经过共享 MLP，再通过 mean/max/count 聚合为 32 维场景编码。该结构不依赖障碍物的输入顺序，且网络输入维度不随障碍物数量变化。

### 3.3 冻结 Base 与 PPO 残差避障

在 S1/S2 中，实际策略动作为：

\[
\Delta q_t=\Delta q_t^{\mathrm{base}}+\Delta q_t^{\mathrm{res}}.
\]

- Base Actor 负责目标到达并保持冻结；
- 残差 Actor 读取机械臂状态和障碍集合编码，用 PPO 学习避障修正；
- 无障碍物时绕过残差网络，动作严格等于 Base 输出；
- 有障碍物时两路均值直接相加，不使用风险门控、残差幅度限制或策略层相加裁剪；
- 最新正式训练中残差软约束权重为 `0`。

25 mm 内关闭残差、仅使用 Base 的逻辑目前只在离线确定性评估中实现，用于验证近目标阶段的残差干扰；它尚未写入正式训练环境，不得将其描述为当前已完成的训练机制。

### 3.4 LSTM 预测与动态障碍物扫掠表示

为复用 S1 的静态 OBB 关系编码，S2 不向 PPO 直接输入障碍物速度。冻结 LSTM 读取动态障碍物过去 10 帧、30 Hz 历史，预测 3 个未来位置，并将当前与未来占据联合构造为一个扫掠 OBB：

\[
S_{i,t}=\operatorname{Sweep}
\left(G_{i,t},p_{i,t},\hat p_{i,t+1:t+3}\right).
\]

对该扫掠 OBB 仍只提取六个胶囊间隙和一个三维方向，因此静态、动态和混合场景共用同一障碍物接口。不使用常速预测器；LSTM 在 PPO 训练中保持 `eval` 模式且不计算梯度。

正式预测模型为：

`outputs/base_models/s2_obstacle_lstm_frozen_v1/obstacle_lstm_frozen.pt`

测试集 ADE 为 `0.116 mm`，FDE 为 `0.198 mm`，FDE P95 为 `0.392 mm`。该结果只证明当前运动分布下的短期预测精度，不代表可预测突然无规则变向。

## 4. 奖励与 PPO 训练设置

### 4.1 最新正式奖励

\[
r_t=r_{\mathrm{goal}}-c_{\mathrm{clearance}}-c_{\mathrm{collision}}.
\]

到达奖励为：

\[
r_{\mathrm{goal}}
=-0.001e_{\mathrm{ref}}^2
-\ln\left(e_{\mathrm{ref}}^2+10^{-4}\right).
\]

障碍物间隙惩罚为：

\[
c_{\mathrm{clearance}}
=5\sum_{j=1}^{6}
\left[
\max\left(0,1-\frac{d_j}{0.15}ight)
\right]^2.
\]

其中 \(d_j\) 是第 \(j\) 个 UR5 碰撞胶囊与最近障碍物的表面间隙。平方 hinge 在 0.15 m 预警区外沿给出弱信号，在接近碰撞时迅速增大，减少远距离避障奖励压制到达的问题。

| 碰撞类型 | 每步惩罚 | 终止回合 |
| --- | ---: | --- |
| 障碍物碰撞 | -300 | 否 |
| 自碰撞 | -300 | 否 |
| 安装平面碰撞 | -300 | 否 |

动态障碍物没有独立的“动态奖励”。扫掠 OBB 经过静态化表示后，与静态障碍物使用同一间隙惩罚和碰撞惩罚。

### 4.2 PPO 与并行采样

| 参数 | 最新 S2 设定 |
| --- | ---: |
| 并行环境 | 16 |
| rollout length | 256 |
| 每次更新样本数 | 4096 |
| \(\gamma\) | 0.99 |
| GAE \(\lambda\) | 0.95 |
| PPO clip ratio | 0.20 |
| 每批 epoch | 20 |
| minibatch | 1024 |
| 优势归一化 | 开启 |
| 归一化优势尾部裁剪 | 5.0 |
| 目标 KL | 关闭 |
| 梯度范数裁剪 | 关闭 |
| 异常对数概率比检查 | \(|\Delta\log p|\le20\) |

最新 200 万步继续训练使用 Actor 学习率 `3e-5`、下限 `1e-5`，Critic 学习率 `1e-4`，并对该次训练预算独立进行线性衰减。

### 4.3 配置继承

`paper_full.yaml` 只是通用基线。最新 S2 实验使用：

`configs/experiments/paper_s2_lstm_sweep_hybrid_threshold15.yaml`

该配置通过继承链将障碍预警距离覆盖为 `0.15 m`，并将残差软约束权重覆盖为 `0`。论文中应以训练目录 `config.json` 和检查点内嵌配置为实验事实，不得只引用父配置的未覆盖默认值。

## 5. 课程学习与当前进展

### 5.1 训练顺序

1. **S0 无障碍物到达：**在真机导向速度约束下训练 PPO Base，达标后冻结。
2. **S1 静态避障：**从单个边长 0.15 m 固定立方体开始，逐步扩展到 1～5 个障碍物混合、多布局以及随机 OBB 尺寸和长宽比。
3. **S2 动态避障：**冻结 LSTM 预测器，使用扫掠 OBB 统一静态和动态障碍表示，持续混入静态场景防止遗忘。

最新 S2 采样比例为：

\[
P(\mathrm{static})=0.25,
\quad P(\mathrm{dynamic})=0.25,
\quad P(\mathrm{hybrid})=0.50.
\]

动态障碍物速度为 `0.05 m/s`。后续阶段继续采样已学场景，而不是只训练当前最难场景。

### 5.2 最新 S2 检查点

`outputs/ppo/s2_clearance_squared_allcollision300_retrain2m_from9891840_seed11001/checkpoints/step_2000000.pt`

本轮从 `step_9891840.pt` 初始化，在 `0.15 m` 平方间隙惩罚和三类 `-300` 碰撞惩罚下追加训练 200 万步。后 40 万步相较前 40 万步，平均回报由 `398.5` 提高到 `477.1`，平均最佳位置误差由 `16.93 mm` 下降到 `13.83 mm`，但训练末期已进入平台区。

### 5.3 确定性评估

不启用 25 mm 接管时：

| 场景 | 回合数 | 碰撞率 | 无碰撞最佳 10 mm / 0.1 rad | 无碰撞最佳 5 mm / 0.05 rad | 最终位置误差中位数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 静态 | 1000 | 6.1% | 38.9% | 14.0% | 31.81 mm |
| 动态 | 500 | 0.4% | 76.8% | 33.2% | 20.34 mm |
| 静动混合 | 500 | 5.6% | 51.6% | 21.0% | 30.44 mm |

这些轨迹的最佳误差明显小于最终误差，表明残差网络在到达目标后仍可能将机械臂推离目标区域。

在同一批随机种子上，评估时于末端位置误差不超过 25 mm 时关闭残差，2000 个回合的无碰撞 `10 mm / 0.1 rad` 达到率由 `51.55%` 提高到 `72.85%`，无碰撞 `5 mm / 0.05 rad` 达到率由 `20.55%` 提高到 `71.30%`，最终位置误差中位数由 `27.96 mm` 降至 `2.80 mm`；总碰撞率从 `4.55%` 变为 `4.75%`。

该结果验证了近目标控制权交接的有效性，但 5 静态障碍物场景的碰撞率由 `7.28%` 增加到 `9.71%`，因此不能直接将纯位置阈值接管定为最终方法。

## 6. 下一步实验和论文验证

1. 在不重新训练的条件下，对比纯 25 mm 接管、目标距离+障碍物间隙条件接管、带回滞的接管。
2. 重点追踪 5 障碍物场景中新增碰撞案例，记录 Base 动作、残差动作、实际执行动作和最小间隙。
3. 确定最终接管规则后，将其放入训练、评估和真机共用的动作组合器，再决定是否需要短期微调。
4. 使用未见随机种子、未见障碍布局和独立测试集，分别报告 S0、S1 和 S2 性能。
5. 按障碍物数量、布局类型、动态/静态类型分组统计，不只报告总体平均值。
6. 对比从头训练、全网络微调、冻结 Base 残差学习、无集合编码和无 LSTM 扫掠表示等消融组。

论文主要评价指标为：无碰撞到达率、障碍物碰撞率、自碰撞率、平面碰撞率、最佳与最终位置/姿态误差、最小安全间隙、动作与速度限制器介入率及任务完成时间。环境内部 `1e-4` 成功阈值过严，不应单独作为论文的实用成功指标；同时报告 `10 mm / 0.1 rad` 和 `5 mm / 0.05 rad` 两组精度。

## 7. 方法边界

- 本课题只验证随机目标位置和固定目标姿态，不宣称适用于任意六维目标位姿；
- 扫掠 OBB 保留未来空间占据，但丢失精确到达时间，属于保守空间近似；
- LSTM 不能预测历史中没有信息的突然随机机动；
- 25 mm 接管结论尚需要障碍物间隙条件和独立随机种子验证；
- 仿真中的速度约束和控制频率已按 CB3.1 UR5 设定，但真机实验仍需要速度降额、急停和安全监控。

# 面向障碍布局变化的机械臂强化学习避障方法研究

## 摘要

机械臂在障碍环境中执行目标到达任务时，需要根据障碍物布局调整运动路径，在避免碰撞的同时满足目标位置与工具朝向要求。强化学习能够通过环境交互获得避障策略，但在有限布局中训练的策略可能依赖特定的空间关系，当障碍物位置及其与目标的相对关系发生变化时，容易出现碰撞、绕障停滞或任务失败等问题。针对障碍布局变化后策略适应能力不足的问题，本文以六自由度机械臂为研究对象，在目标位置随机、目标姿态相对于机器人基座固定的任务设定下，研究面向未见障碍布局的强化学习避障方法。

首先，在固定目标姿态下构建可达位置采样方法，利用末端虚拟关键点将位置和姿态偏差转化为对应关键点之间的几何距离，以近端策略优化算法学习六关节运动策略，建立无障碍条件下对随机目标位置的到达能力。运动过程中允许末端姿态变化，最终同时满足目标位置和规定姿态的精度要求，为不同障碍布局中的避障学习提供基础。

其次，针对策略对特定障碍布局的依赖，结合障碍物相对位置与连杆安全距离构建环境状态表征，在统一的观测和动作空间下学习依据当前几何关系进行决策的避障策略。同时，协调目标接近与碰撞规避的奖励，引导机械臂在绕开障碍后继续到达目标，兼顾整臂安全与任务完成。

再次，针对复杂布局下探索困难及场景切换后的能力退化问题，设计结合布局多样化采样的课程学习与混合训练方法。按照无障碍到达、静态避障和动态避障的顺序逐步增加任务难度，在后续阶段持续采样已学习场景，并结合短时运动信息扩展动态障碍场景中的决策能力，研究同一策略对不同障碍布局的适应与能力保持。

最后，构建训练布局与测试布局相互独立的仿真实验体系，保持统一目标姿态和一致的目标位置采样条件，在冻结策略参数、不重新训练的条件下，开展未见障碍布局测试、多场景联合测试及关键模块消融实验。通过安全到达成功率、碰撞率、位置与姿态误差、最小安全距离和任务完成时间等指标，分析不同布局变化程度下的策略性能及泛化边界，为变化障碍环境中的机械臂自主运动控制提供方法参考。

# 面向障碍布局变化的机械臂强化学习避障方法研究

## 摘要

机械臂在非结构化环境中执行目标到达任务时，需要根据障碍物的数量、形状、位置和运动状态调整运动路径。传统强化学习避障策略容易依赖有限训练布局，当障碍布局改变时，可能出现碰撞、绕障停滞以及到达能力退化。针对上述问题，本文以六自由度 UR5 机械臂为对象，研究目标位置随机、目标姿态固定条件下，面向障碍布局变化的强化学习避障方法。

首先，在按 CB3.1 UR5 关节速度和加速度约束建立的仿真环境中，采用近端策略优化算法训练无障碍物到达策略，建立随机目标位置与固定目标姿态下的高精度到达能力，并将该策略作为后续避障学习中的冻结基础策略。

其次，针对障碍物数量和几何外形变化导致策略输入不统一的问题，利用有向包围盒与机械臂六个碰撞胶囊的有符号间隙和最近表面方向构造单障碍物特征，通过共享编码与无序集合聚合得到固定长度场景表征。在此基础上，冻结到达策略，使用 PPO 残差网络学习障碍条件下的关节动作修正，以保持无障碍物到达能力并学习多布局避障。

再次，针对动态障碍物的未来占据难以由瞬时几何状态表示的问题，使用冻结 LSTM 根据历史轨迹预测未来位置，将障碍物当前与未来占据构造为整体扫掠 OBB，使动态障碍物复用静态障碍物的集合编码和避障奖励。按照无障碍物到达、静态避障和动态避障的顺序逐步增加任务难度，并在后续阶段持续混合已学场景，降低能力遗忘。

最后，建立静态、动态和静动混合的分组确定性评估方法，从无碰撞到达率、障碍物碰撞率、自碰撞率、安装平面碰撞率、位姿精度和最小安全间隙等方面验证方法。当前结果表明，冻结到达策略、障碍集合编码和残差避障可以完成不同数量及类型障碍物下的到达任务；近目标控制权交接能显著改善最终精度，但在拥挤多障碍物场景中仍需进一步兼顾安全性。

**关键词：**机械臂；强化学习；安全避障；障碍集合编码；残差策略；课程学习；动态障碍预测

# 训练与实验说明

核对日期：2026-11-02。第 1～3 节记录当前代码，第 4 节记录待开展实验，第 5 节仅保留旧实验摘录。

当前主配置已实现：**目标位置随机，目标完整姿态相对于机器人基座固定；绕障过程中允许改变姿态，最终恢复统一目标姿态。**`keypoint` 和 `reference_ppo` 共用固定姿态任务：初始关节角 `[45, -90, 90, 0, 45, -90]` 度，目标欧拉角 `[0, 1.57, 1.57]` rad，随机目标位置经过同一套 IK/FK、关节范围与目标碰撞筛选。S0/S1/S2 使用同一任务定义，S0 保留纯到达分支。

## 1. 当前入口与模式

训练入口为 [train_thesis_ppo.py](../scripts/core/train_thesis_ppo.py)，主配置为 [paper_full.yaml](../configs/experiments/paper_full.yaml)，算法实现为 [thesis_ppo.py](../src/rl_risk_sac/algorithms/thesis_ppo.py)。包名 `rl_risk_sac` 是现有路径，不表示训练算法仍是 SAC。

| 项目 | `keypoint` | `reference_ppo` |
| --- | --- | --- |
| 输入 | 38 维：原36维加剩余时间、连续保持进度；无 Jacobian | 25 维参考观测 |
| 动作执行语义 | 策略输出直接作为绝对目标关节角，S1/S2 对对应位移执行安全投影 | 将策略输出直接作为绝对目标关节角 |
| 策略输出裁剪范围 | 每关节 `[-3.14, 3.14]` rad | 每关节 `[-3.14, 3.14]` rad |
| 初始状态与目标 | 固定弯曲准备构型、固定目标姿态；参考位置提议经实际 IK/FK 与目标碰撞筛选 | 与关键点模式相同，直接复用同一采样器 |
| 到达标准 | 位置误差≤0.01 m、姿态误差≤0.10 rad，连续保持5步 | 与关键点模式相同 |
| 环境数量 | 支持多环境，命令行默认 8 | 强制 1 个环境 |
| 每次更新的采样量 | 默认 8 环境 × 每环境 512 步，即 4096 条 transition | 强制每次收集 4096 步 |
| 折扣计算 | 配置中的固定 gamma | 根据动作 log probability 计算的动态 gamma |

两种模式不只是奖励不同。比较障碍编码或布局采样时，应固定使用同一种模式，不能把模式差异归因于待研究模块。

### 关键点 v2（2026-11-02）

关键点误差九维按1 m线性归一化，不再硬裁剪。最后两维依次为剩余步数/100、连续保持次数/5；后者使用当前动作执行后的计数。原有障碍与自身间隙位置不变，S0 的15维安全输入仍为常量，S1/S2 使用同一38维结构。

统一关键点距离为 $D=0.6\operatorname{mean}(d_i)+0.4\max(d_i)$，令 $z=D/0.03$、$C=0.001z^2+\ln(1+z^2)$。普通步骤到达奖励为 $-0.1-0.9C/(1+C)$，始终在 $[-1,-0.1]$ 内，不单独奖励位置、姿态或历史最佳。成功步骤直接为+100，硬失败为-250，超时为-50，均替换普通奖励。S0 自碰撞仅在非终端步骤额外扣1；终端事件不重复叠加该扣分。S1/S2 仍按原场景逻辑处理安全投影、碰撞终止和安全代价。

关键点回合100步上限是任务期限：超时 `terminated=True`、`truncated=False`，不自举终端价值；PPO rollout 切段仍自举。参考模式保留其截断与过程奖励逻辑。目标关节角距 URDF 硬限位留0.02 rad裕量，实际超出硬限位0.001 rad才判越界，关键点模式明显越界会提前停止物理子步。固定姿态目标的IK解转换到等价关节周期并检查绝对动作可执行范围。

两种模式共同修正：Actor 均值为 $3.14\tanh(f(s))$；保存原始高斯样本与概率，仅裁剪执行命令。参考模式多次采样平均时，按条件标准差 $\sigma/\sqrt{k}$ 计算并保存概率，更新时使用相同因子。两种模式的初始均值都围绕同一准备构型（不使用目标IK）；关键点模式初始标准差0.20 rad，参考模式初始标准差仍为1.0 rad。两种模式均开启优势归一化、Actor/Critic 独立梯度范数裁剪0.5，每批最多10轮更新。

新关键点训练必须新建 run，从头启动，不能加载旧36维/增量控制checkpoint。旧版参考checkpoint也因策略概率合同变化而拒绝直接加载。已运行的旧进程不会热加载这些改动，仍按启动时版本继续运行。

参考模式任务对齐后不再代表原论文任务的原样复现：旧零初态、未筛选目标分布的参考结果不能直接作为同任务基线。建议新建run从头训练。兼容v2权重若用于迁移，应明确这是新任务上的初始化，而不是旧实验精确续训。25维参考观测、参考奖励、动态gamma、单环境及碰撞/超时处理保留。

v2 验证：26项回归测试通过，包含S1/S2完整分支；CPU、8环境、4096条样本完成一次默认关键点PPO更新，40个已结束回合均运行100步、执行动作裁剪率0，保存的38维checkpoint重新加载通过。参考模式128步采样与更新、25维checkpoint保存加载通过。种子31001的100个目标均通过验证，最大IK位置/姿态残差0.003898 m/0.003936 rad；20/20端点保持、20/20已知关节目标跟踪成功且无碰撞，平均7.9步。短训练和已知IK诊断不代表策略收敛或成功率结论。

### 固定姿态目标与预检查

配置入口为 `thesis.fixed_orientation_goal`，其中 `enabled` 开启该任务，`euler_rad` 与 `initial_joint_positions_rad` 保存固定旋转及初态。参考位置提议满足半径不超过 0.75 m、xy 半径不小于 0.30 m、y 非负且 z 不低于 0.05 m。两种模式均检查完整姿态 IK/FK、关节限位、目标自碰撞和自碰撞间隙，失败时重新提议，不把未验证目标标为可达；求解后恢复原始关节状态。旧随机姿态和姿态分桶逻辑不进入该分支。

初始构型按 shoulder_pan、shoulder_lift、elbow、wrist_1、wrist_2、wrist_3 顺序为 `[0.785398, -1.570796, 1.570796, 0, 0.785398, -1.570796]` rad：上臂抬起、肘部弯曲约 90°、前臂向前伸出。初始末端约 `(0.200182, 0.436843, 0.419509)` m，自碰撞最小间隙约 0.01218 m；当前同一米／弧度几何雅可比约定下，最小奇异值约 0.2160、条件数约 9.08。初始朝向与规定目标朝向相差约 0.00113 rad，不强制运动途中保持该朝向。这些是当前模型的局部初态检查，不是全路径安全保证或全局最优初态证明。

IK 仅用于生成有效目标，IK 关节解不作为策略输入或训练动作。筛选会改变接受目标的位置分布，不宣称覆盖全部理论可达位置；起点和终点无碰撞不代表直线关节路径无碰撞。训练时另保存 `config.json`，记录实际加载的配置和任务参数。旧随机姿态模型的权重即使维度兼容，也不作为新任务已验证的基线。

## 2. 当前阶段采样与碰撞处理

以下比例来自训练器的 `stage_scene()`，不是旧文档或 YAML 中残留的阶段比例：

| 阶段 | 无障碍 | 静态障碍 | 动态障碍 |
| --- | ---: | ---: | ---: |
| S0 | 100% | 0% | 0% |
| S1 | 35% | 65% | 0% |
| S2 | 20% | 40% | 40% |

主配置下位置阈值为 0.01 m、姿态阈值为 0.10 rad，连续满足 5 个决策步才成功。当前训练器没有 L0–L13 精度升档，也没有旧 SAC 的按档位 Replay。

S0 启用纯到达分支：不运行外部避障流程，关闭安全 shaping 和自安全投影。`keypoint` 模式保留每个检测到自碰撞的决策步 `-1` 惩罚，自碰撞不直接结束回合。S1/S2 使用完整避障分支；`keypoint` 模式下 S1 外部接触不直接终止，S2 严格外部接触会终止，自碰撞等硬失败可终止回合。`reference_ppo` 另有碰撞惩罚且不因碰撞直接终止，不能套用关键点模式的终止解释。

静态阻挡场景尝试将球体放在初始到目标的关节直线路径上，并筛选起点和目标的间隙；没有候选时可能回退普通随机位置。因此，“启用阻挡采样”不等于每个场景都必须绕行，也不证明存在其他可行路径。

## 3. 恢复与日志边界

- `--resume` 加载 agent 权重和可用优化器状态，并从checkpoint的 `global_step`（旧checkpoint回退使用 `step`）恢复全局训练步数。`--steps` 仍表示本次新增transition数；学习率衰减使用“历史步数+本次步数”的全局进度。旧的多段续训checkpoint若没有正确全局计数，可用 `--initial-global-step` 显式覆盖。环境状态、未完成rollout和随机数状态仍不做精确恢复。
- 恢复或阶段接续应保持输入维度、动作、奖励及任务采样语义兼容，不直接跨 `keypoint` 与 `reference_ppo` 模式加载；旧零初态参考模型与当前对齐任务也不能混作同一实验。
- 默认每次 PPO 更新输出日志，完整 rollout 对应4096条transition，可用 `--log-interval` 调整。每10次更新保存checkpoint，正常结束或键盘中断也保存经过有限值检查的权重；异常退出不覆盖正常checkpoint。中断保存不是环境/rollout的精确续训快照。
- `episodes.csv` 增加终止原因、全回合碰撞、终点碰撞、最佳/最终位置与姿态及关键点误差、最长连续保持、动作裁剪率和奖励分项；`step` 是全局步数，`run_step` 是本次命令新增步数。`updates.jsonl` 另保存 Actor/Critic 学习率、Actor提案/接受/回滚次数、Critic独立更新次数、完整rollout KL及自适应学习率倍率。`summary.json` 是训练摘要，不是冻结测试报告。
- 训练器没有自动完成独立布局泛化评估或完整 S0→S1→S2 验收流程。旧文档中的评估脚本、promotion gate 和 `strictify` 命令不能继续使用。

### PPO 数值保护

主实验与基础配置均使用 `normalize_advantage: true`、`max_grad_norm: 0.5`、`epochs: 10`、`target_kl: 0.02`、`max_abs_log_ratio: 20.0`；参考模式不再照搬原实现中关闭归一化、关闭梯度裁剪和20轮重复更新的设置。奖励和环境规则不因本次数值保护改变。

先检查批次、当前/旧对数概率及其差值均为有限值。若任一样本的 $|\log\pi_{new}-\log\pi_{old}|>20$，在取指数前直接保存现场并报错，不截断差值、不替换 NaN、不跳过异常继续训练。概率比、损失和梯度也接受有限值检查。每次优化前后检查 Actor、Critic、可学习标准差，以及 Adam 的步数、动量和二阶矩等状态；加载和保存checkpoint也检查有限值。

正常更新中使用 $\widehat{KL}=\operatorname{mean}[\exp(\Delta\log p)-1-\Delta\log p]$，数值上用 `expm1` 计算。每个 Actor 小批次提案后，都在完整rollout上重新计算新旧策略KL。超过 $1.5\times0.02=0.03$ 时，立即恢复提案前的 Actor 参数、可学习标准差和 Adam 状态；关键点模式同时把 Actor 学习率乘0.5，停止该rollout剩余Actor提案。Critic与Actor门控解耦，仍对完整rollout执行全部配置轮次。已接受Actor状态的完整rollout KL不超过0.03。

关键点模式的基础学习率使用全局步数线性衰减：Actor从 `3e-4` 到 `3e-5`，Critic从 `3e-4` 到 `1e-4`。连续10个更新的已接受最大KL均低于0.01时，Actor自适应倍率乘1.05，但不超过基础衰减上限；发生KL拒绝则倍率乘0.5，且最终学习率不低于 `3e-5`。自适应倍率和低KL计数写入checkpoint。

数值异常时，在运行目录 `diagnostics/ppo_failure_*.pt` 保存完整训练批次、出错小批次索引、概率差及损失、梯度、异常时模型/优化器状态、更新前有效快照、随机数状态和训练上下文。保存现场后回滚本轮完整PPO更新（若更新前已损坏则无法回滚），明确抛错并停止；不会静默重试，也不会从 `finally` 写出污染checkpoint。采样阶段等其他异常另存部分rollout诊断。诊断文件不是可直接精确续训的checkpoint。

当前回归测试共46项通过。历史失败批次复算中，旧实现会产生约0.157的KL；新实现准确回滚Actor和Adam状态，将Actor学习率从约 `2.25e-4` 降至 `1.12e-4`，同时Critic完成40次更新。使用200万步checkpoint进行4096步真实环境续训短测，完成Actor/Critic各40次更新，已接受最大KL为0.0181，并正确保存全局步数2004096的checkpoint。短测只验证数值与训练链路，不证明长期收敛。

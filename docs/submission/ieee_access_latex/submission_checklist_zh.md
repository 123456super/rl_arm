# IEEE Access 投稿前核对表

## 投稿前 2-4 周

- [ ] 确认 IEEE Access 是否仍被 Ei Compendex 收录。
- [ ] 向上海大学图书馆确认 IEEE OA 协议、APC 减免、剩余额度和申请流程。
- [ ] 确认通讯作者邮箱、单位写法和学校要求。
- [ ] 确认所有作者顺序，投稿后改作者非常麻烦。
- [ ] 通讯作者准备 ORCID，并确保 ORCID 公开可见且信息完整。

## LaTeX 与格式

- [ ] 使用 IEEE Access 官方 LaTeX 模板。
- [ ] 双栏、单倍行距。
- [ ] 源文件和 PDF 内容完全一致。
- [ ] 全部文件小于 40 MB。
- [ ] 摘要为单段。
- [ ] 摘要中没有编号公式。
- [ ] 摘要中没有编号引用。
- [ ] 关键词 3-10 个。
- [ ] 所有缩略词第一次出现时均已定义，包括摘要中的缩略词。
- [ ] 全部图和表都在正文中被引用。
- [ ] 全部正文引用的图和表都实际存在。
- [ ] 所有作者 biography 放在参考文献之后。

## 内容质量

- [ ] Introduction 清楚说明问题、挑战、现有不足和本文贡献。
- [ ] Related Work 覆盖机械臂避障、强化学习、安全/风险感知 RL、动态障碍物。
- [ ] Method 中有清楚的状态、动作、奖励、终止条件、风险定义。
- [ ] Experiments 中有训练设置、评价设置、随机种子、超参数。
- [ ] 至少有主方法与无风险 SAC 的对比。
- [ ] 至少有一个消融实验证明风险项有效。
- [ ] 结果用均值和标准差或置信区间呈现。
- [ ] 结论中的所有说法都有实验数据支撑。

## 伦理与完整性

- [ ] 没有一稿多投。
- [ ] 没有使用撤稿文献作为关键依据。
- [ ] 引用准确，没有编造引用。
- [ ] 若使用 AI 辅助写作、润色、代码理解或图片生成，已在 Acknowledgment 中披露。
- [ ] 如果复用学位论文、会议论文或预印本内容，已按 IEEE 要求说明。
- [ ] 如果复用他人图片，已获得权限并在 caption 中注明来源。

## 投稿材料

- [ ] LaTeX 源文件。
- [ ] PDF 文件。
- [ ] BibTeX 或参考文献文件。
- [ ] 图片源文件或高分辨率图片。
- [ ] 作者 biography。
- [ ] Graphical Abstract 草图。
- [ ] 避障演示视频，若准备提交，控制在 100 MB 以内。
- [ ] Cover letter。
- [ ] Opposed reviewers list，如需要。

## 录用后

- [ ] 提交最终 LaTeX/Word 文件。
- [ ] 提交 `FINAL Article.pdf`。
- [ ] 提交 Graphical Abstract，推荐 660 x 295，JPG，小于 45 KB。
- [ ] 完成电子版权表。
- [ ] 处理 APC 或学校 OA 协议流程。
- [ ] 校对 page proof。
- [ ] Early Access 上线后记录 DOI、IEEE Xplore 链接和发表日期。
- [ ] 后续跟踪 Ei Compendex 检索状态。

## 1. 当前论文主线

```text
Instant-Link-SAC 当前风险名义策略
-> 候选动作条件的全身连杆间隙预测
-> One-Step-QP 与 Predictive-Trajectory-QP
-> 同一 quintic 子步命令上的安全 + 位置/速度/acceleration/jerk 约束
-> 一致下发、逐子步反馈监测与条件允许时的低速实机验证
```

当前已完成的基线结果只能支撑“当前连杆级风险是合理起点”。不能把它们写成预测风险、完整 QP 或真实部署已经验证。完整数值和结论边界见 [实验结果事实源](thesis_experiment_results.md)。

### 主线一致性审计结论（2026-09-09）

- **主线锁定。** 后续不再改成新的 RL 算法。论文核心固定为“已有 Instant-Link actor + 动作条件多时刻全身间隙 + 轨迹一致标准 QP”。
- **核心对照唯一。** `One-Step-QP` 与 `Predictive-Trajectory-QP` 使用同一 actor、RTB、OSQP、运动边界、slack 和 episode seeds，只改变是否使用未来动作条件几何；因此预测贡献可被单独识别。
- **非核心项剥离。** Predictive-Link-SAC 是负消融；Softmax 聚合、风险自适应权重、RTB actor 重训、多障碍和实机均不是主方法完成的必要条件。
- **可实现性判断。** 现有代码已有胶囊体、当前距离、quintic 子步命令、有限差分 Jacobian、固定 actor 评估和成对实验框架；conda `rl` 中已有 `osqp` 与 `scipy`。QP 不为每个时刻新增控制变量，核心变量始终是 6 维安全 endpoint，另加少量活跃 safety slacks；新增工作集中在逐子步监测、候选动作运动学外推、逐时刻距离梯度和标准 QP 接入，属于中等规模增量实现，不要求重新训练主策略。
- **论文定位。** 该路线适合做工程方法与系统实验型论文，不应包装成新的 SAC 理论或形式化安全证明。创新是否足够，必须由相对 One-Step-QP 的预测增益、线性化误差、实时性和鲁棒性消融共同支撑。
- **不再换线规则。** P3/P6 若未取得收益，只能按预注册的误差、活跃集、slack 和失败轨迹分析原因；不得在 held-out 上继续调参，也不得把另一种未验证模块临时改称核心创新。

## 3. 当前阻塞与判定

- `Predictive-Link-SAC` 已明确未过门控，不作为主贡献；已准备但未运行的 excess shaping 停止执行，避免围绕负方向继续消耗预算。
- 旧三方法表仍只作历史记录；修复后的正式表已使用 13,500 个无重复 episode 单元，二者不得混用。
- 现有安全指标只在 20 Hz 控制周期末采样，可能漏掉 240 Hz 子步间的瞬时最小距离或接触；P6 前必须修复，旧结果保留为历史口径。
- 历史 `safety_qp_infeasible` 只是 8 次投影后仍有残差，`active_constraints` 也未正确表达活跃约束数量；二者不能用于标准 QP 结论。
- 现有 P5 只证明发出的 endpoint/quintic 命令峰值可控，不能宣称反馈运动边界或逐子步安全已在统一 QP 中验证。
- 已有 actor 在 EMA 下训练而安全层实验使用 RTB；成对反事实仍可识别安全层增益，但不能宣称训练—部署执行器完全一致。
- 真实机器人控制接口、限速、急停、RGB-D 失效停止、相机外参和碰撞包络仍需现场签核。

## 4. 下一步优先级

1. 修复逐物理子步状态/距离/接触采样、命令与反馈导数分栏，以及投影残差/活跃约束命名。
2. 实现固定 Instant-Link actor 候选动作下的短时连杆间隙外推与梯度检查。
3. 接入 OSQP，先完成同一求解器下的 One-Step-QP，再加入多时刻预测约束形成 Proposed；主方法使用固定权重。
4. 在 seed 2001 上冻结参数后运行独立 held-out；随后做噪声、延迟和速度突变，实机验证以硬件和安全签核为条件。

## 5. 论文写作边界

当前可以写：

- 修复后的正式三方法基线包含 13,500 个无重复 episode 单元；`link_fixed_penalty1` 宏平均成功率为 61.33%，碰撞率为 6.80%，优于本轮 `ee_fixed` 和 `ldrc_fixed`；
- `link_fixed_penalty1` 是预测风险和安全 QP 的扩展基线；
- action-independent 预测风险在固定策略离线评估中具有正预警提前量，但误报偏高；
- 在固定 `Instant-Link-SAC` actor 的独立-seed 五场景反事实中，反应式投影器将控制周期采样碰撞率从 6.91% 降至 1.49%，安全违反率从 1.519% 降至 0.238%，成功率未下降且子步命令 RMS jerk 未升高。
- endpoint/quintic 过渡消融中，`a_max=12 rad/s^2`、`j_max=500 rad/s^3` 将子步命令全局最大 acceleration/jerk 限制为 8.335/500.005，并将平均 episode 命令 peak jerk 降低约 9.3%；该结果不等同于反馈运动约束或最终 Predictive-Trajectory-QP。

当前不能写：

- `Predictive-Link-SAC` 已经优于 `Instant-Link-SAC`；
- 当前 endpoint/quintic P5 已经证明关节反馈边界或逐预测子步安全约束有效；
- 把旧 seed 重叠表继续表述为 13,500 个独立评估 episodes，或与修复后的正式表混用；
- 动作条件 Predictive-Trajectory-QP 已经在多场景中降低碰撞；
- 完整 `Proposed` 方法已经得到验证；
- 真实 UR5 实验已经证明方法有效或提供形式化安全保证。

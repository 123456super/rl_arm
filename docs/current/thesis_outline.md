## 一、研究背景与意义

随着机械臂逐渐进入人机协作、柔性制造和非结构化作业环境，其控制系统不仅需要完成目标到达任务，还需要对运动障碍物形成实时、整臂和具有提前量的安全响应。机械臂碰撞可能发生在上臂、肘部、前臂和腕部等任意部位，仅使用末端执行器距离或整臂单一最小距离，容易遗漏碰撞部位及局部运动趋势。

动态避障风险不仅由当前距离决定，还取决于障碍物和连杆的相对速度、运动方向及未来一段时间内的距离变化。一个当前距离较远但快速接近的障碍物，可能比一个距离较近但正在远离的障碍物更危险。因此，仅依据当前时刻的距离、接近速度或径向近似 TTC 进行反应式避障，仍可能出现预警不足和动作修正滞后的问题。

Soft Actor-Critic（SAC）适合机械臂关节速度连续控制，但单纯依靠奖励惩罚学习安全行为存在两方面局限：一是安全性依赖奖励权重和训练数据覆盖；二是策略在未见状态下仍可能输出危险动作。约束强化学习能够分离任务奖励与风险代价，但其安全效果仍受约束阈值、代价建模和训练稳定性影响，不能直接等同于部署阶段的动作安全保证。

基于以上问题，本文固定一条不依赖重新训练成功的主线：“当前连杆风险 SAC 名义策略—动作条件全身间隙预测—轨迹一致预测安全 QP—逐子步监测”。首先，以胶囊体表示机械臂主要连杆，并使用已有 Instant-Link-SAC 生成名义关节速度；其次，对候选动作诱导的短时机器人运动和障碍物运动进行联合外推，形成逐连杆、逐时刻预测间隙；然后，将本周期实际下发的 quintic 子步速度轨迹作为安全终点速度的仿射参数化，在同一凸 QP 中约束预测间隙和关节运动边界；最后，执行优化器建模的子步命令，并使用仿真状态或机器人反馈进行逐子步监测和异常降级。

本文与“强化学习 + 实时碰撞检测 + 事后轨迹融合”的一般框架保持明确区别：quintic 轨迹不是安全 QP 之后的独立滤波，而是进入优化模型的确定性仿射基函数；安全约束检查的是实际将执行的每个子步。研究重点不是动态目标视觉跟踪，而是运动障碍物条件下候选动作对全身不同连杆未来间隙的影响，以及安全与运动连续性在同一低维在线优化中的耦合。

## 二、研究目标

本文面向固定基座 UR5 机械臂在单动态球形障碍物环境下的静态目标位置到达任务，研究具有短时预测能力的整臂安全强化学习控制方法。主要目标如下：

1. 建立 UR5 主要连杆胶囊体模型，准确计算连杆—障碍物表面距离、最近点、相对接近速度和碰撞趋势。
2. 提出动作条件的预测性连杆风险表征方法，对 SAC 候选动作下的机器人子步运动与障碍物运动联合外推，获得未来最小间隙、首次越界时间和危险连杆集合。
3. 提出轨迹一致的 jerk 约束安全 QP：以名义终点速度参数化完整 quintic 子步命令，在同一优化中施加逐连杆预测安全、关节速度与位置、acceleration 和 jerk 约束，并分别验证下发命令与关节反馈。
4. 使用固定权重和固定约束筛选规则完成主方法；风险自适应权重仅作为可选消融，只有 validation 显示稳定收益时才进入最终方法。
5. 在 PyBullet 中完成任务、安全、提前预警、干预程度、命令平滑性和鲁棒性验证；具备硬件与安全签核条件时，再做低速真实 UR5 可执行性验证。

## 三、拟创新点与论文定位

### 3.1 核心创新点

1. **面向候选动作的全身连杆短时安全间隙预测。** 在已有连杆距离和当前运动趋势之外，显式评价 SAC 名义动作诱导的机器人轨迹与障碍物局部运动，计算逐连杆、逐时刻间隙及其对候选安全终点速度的局部梯度。方法核心输出是可验证的物理间隙约束，不依赖人为加权的单一风险分数。

2. **轨迹一致的全身预测安全 QP。** SAC 负责生成名义终点速度；quintic 子步命令对安全终点速度是已知仿射映射，在线 QP 因而能够在同一变量上约束实际下发的逐子步速度、位置、加速度、jerk，以及短时预测连杆间隙。该设计避免“安全层输出一个速度、后级插值又改变它”的接口漏洞。活跃集和线性化点在每个周期求解前确定，使单次在线问题保持为凸 QP。

### 3.2 验证性贡献

3. **面向预测与干预机制的分层评价体系。** 构建随机穿越、重点连杆压迫、速度突变、观测噪声和预测误差等场景，除成功率和碰撞率外，引入首次预警提前量、安全层介入率、动作修正幅度、风险连杆识别率等指标，区分“是否感知到风险”“是否及时干预”和“是否完成任务”。该部分属于实验与评价贡献，不表述为独立算法创新。

### 3.3 非创新内容与结论边界

- SAC、预测安全滤波、凸 QP、quintic 时间标度、距离线性化以及 acceleration/jerk 限制均有相关工作；本文不主张发明这些组件。创新主张限定为：面向整臂胶囊体的动作条件多时刻间隙约束，与实际下发 quintic 子步命令在同一 6 维终点速度 QP 中的一致耦合。该主张能否成立最终取决于文献对比和 P3/P6 消融，而不是由方案描述自动成立。
- 已完成实验表明，将预测风险直接扩展进 SAC observation 或以固定权重加入 reward 未获得任务与安全的共同收益；`Predictive-Link-SAC` 因此降级为失败消融，不再作为最终方法的必要组成。
- 固定风险惩罚 SAC 与约束 SAC 的比较属于前期研究和对比实验。已有结果未证明约束 SAC 整体优于经标定固定惩罚 SAC，因此约束 SAC 不再作为论文核心创新。
- 历史滤波系数自适应方案未获得稳定收益且增大 jerk，仅作为方法选择过程中的失败经验保留，不纳入正式控制管线。
- 在感知误差、离散控制、几何近似和软约束存在时，本文不宣称“绝对无碰撞”。安全层只能在所列模型假设和可行域条件下提供显式动作约束。

## 四、研究范围与关键问题

### 4.1 研究范围

| 类别 | 本文范围 | 不作为重点的内容 |
| --- | --- | --- |
| 机械臂 | 固定基座 UR5，主要连杆整臂避障 | 移动基座、自碰撞、末端姿态精确控制 |
| 任务 | 静态目标点到达 | 动态目标视觉伺服与复杂操作任务 |
| 障碍物 | 单个动态球形障碍物；低到中等速度 | 多障碍物、非规则物体、复杂遮挡 |
| 感知 | 仿真真值；实机 RGB-D 位置与速度估计 | 复杂目标检测和多传感器融合 |
| 控制 | SAC 名义策略、预测风险、jerk 约束安全 QP 指令整形 | 在线真实机器人强化学习 |
| 验证 | PyBullet 主验证，真实 UR5 低速部署验证 | 高速或接触式安全认证实验 |

多障碍物可作为附加泛化实验：对每个障碍物分别计算连杆风险和安全约束，再统一求解动作修正，但不扩展为论文主问题。

### 4.2 拟解决的关键问题

- **如何稳定表示整臂局部风险。** 最近连杆编号和硬最大风险可能在相邻连杆间跳变，需要在保留最危险部位信息的同时降低风险聚合不连续性。
- **如何获得有意义的短时预测。** 需要明确当前状态外推、候选动作外推和感知速度误差的适用边界，避免将匀速预测夸大为精确轨迹预测。
- **如何最小化安全干预对任务的影响。** 安全层既要阻止高风险动作，也要避免频繁介入导致机械臂停滞、绕行过度或动作震荡。
- **如何统一安全修正与实际执行轨迹。** 独立的后级滤波或插值可能改变已经满足安全约束的动作，因此本文将确定性 quintic 子步映射嵌入安全 QP，使优化变量唯一确定完整执行轨迹，并在相同模型内约束安全、加速度与 jerk。
- **如何通过消融验证新增方法。** 实验必须分别验证预测风险和安全修正层，不能只比较完整方法与末端风险基线。

## 五、文献综述与总体技术路线

### 5.1 文献综述安排

文献综述围绕以下五条线索展开：

1. 机械臂动态避障：人工势场、采样规划、速度阻尼、MPC 和 CBF-QP 的实时性与安全边界。
2. 整臂几何建模：胶囊体、最近点距离、距离梯度和连杆雅可比。
3. 碰撞趋势预测：相对速度、TTC、有限时域最小距离和不确定性条件下的风险度量。
4. 强化学习机械臂控制：DDPG、TD3、SAC，以及奖励惩罚和约束强化学习的安全性局限。
5. 学习控制与安全指令整形：名义策略、安全盾、动作投影、jerk 约束和风险自适应控制之间的接口设计。

文献缺口拟归纳为：现有学习型机械臂避障常关注末端或当前最小距离；部分方法虽然加入实时碰撞检测，却没有显式建模不同连杆未来一段时间内的风险分布；仅依靠奖励学习也难以处理策略输出中的偶发危险动作。

| 常见做法 | 局限 | 本文拟改进 |
| --- | --- | --- |
| 末端风险或当前全局最小距离 | 易遗漏非末端风险及未来接近趋势 | 逐连杆有限时域风险预测 |
| `max_i Risk_i` 硬聚合 | 最危险连杆切换时可能不连续 | Softmax 聚合并保留 Top-k 风险信息 |
| 预测风险直接进入 SAC 状态/奖励 | 高维相关噪声与误报可能降低样本效率并诱发保守策略 | 当前风险 SAC 名义控制 + 动作条件预测安全层 |
| 仅在碰撞后给予惩罚 | 信号稀疏且缺少提前量 | 未来最小间隙和首次越界时间 |
| 安全修正与平滑串联 | 后级滤波或插值可能改变安全动作 | 将实际子步轨迹参数化嵌入同一 QP |

### 5.2 总体技术路线

```mermaid
flowchart LR
    A[机器人、目标与障碍物状态] --> B[整臂胶囊体与最近点]
    B --> C[当前连杆动态风险]
    C --> F[Instant-Link-SAC 策略动作]
    F --> G[rate limit + Butterworth 名义 endpoint]
    G --> D[候选 endpoint 与障碍物联合外推]
    D --> E[逐连杆逐子步预测间隙]
    E --> H[Top-k 预测约束与风险调度]
    G --> I[轨迹嵌入式 jerk 约束安全 QP]
    H --> I
    I --> J[安全指令、子步监测与执行]
    J --> A
```

总体流程如下：

1. 获取关节状态、目标位置、障碍物位置与速度。
2. 计算各连杆胶囊体、最近点、表面距离和对应点速度。
3. SAC 生成策略速度，经与 P5 一致的 policy rate limit 和 Butterworth 滤波得到名义 endpoint；滤波器只位于 QP 前，不得在 QP 后再次改变安全 endpoint。
4. 将该名义 endpoint 对应的 quintic 子步轨迹与障碍物运动联合外推，形成逐连杆、逐子步预测间隙。
5. 选择 Top-k 危险连杆和有效预测时刻，在线线性化为安全约束。
6. 在同一 QP 中优化终点速度；quintic 仿射映射使该变量唯一确定完整子步速度、加速度和 jerk，并允许直接施加物理硬边界。
7. 严格执行 QP 已建模的子步轨迹；若安全松弛或线性化误差超限，则降级或停止。
8. 在物理子步持续监测最小距离、预测风险和感知状态，异常时限速或停止。

## 六、主要研究内容

### 6.1 机械臂整臂几何建模

第 `i` 个主要连杆采用胶囊体近似，球形障碍物由中心、速度和半径描述：

```text
L_i(q) = {p_i^a(q), p_i^b(q), r_i}
O_t = {c_t, v_t, R}
```

障碍物中心到连杆轴线的最近点和表面间隙为：

```text
u_i = p_i^b - p_i^a
rho_i = clip(((c - p_i^a)^T u_i) / (u_i^T u_i), 0, 1)
x_i = p_i^a + rho_i u_i
d_i = ||c - x_i|| - r_i - R
n_i = (c - x_i) / (||c - x_i|| + epsilon)
```

连杆对应点速度优先由雅可比计算：

```text
v_i^link = J_i(q, rho_i) q_dot
dot_d_i = n_i^T (v - v_i^link)
v_i^app = max(0, -dot_d_i)
```

有限差分实现必须固定当前投影系数 `rho_i`，避免将最近点沿连杆滑动误认为连杆自身速度。

### 6.2 当前连杆动态风险基线

当前时刻径向近似 TTC 定义为：

```text
if d_i <= d_safe:
    TTC_i = 0
elif v_i^app <= epsilon_v:
    TTC_i = TTC_max
else:
    TTC_i = min((d_i - d_safe) / v_i^app, TTC_max)
```

基线连杆风险为：

```text
R_d_i = clip(exp(-(d_i - d_safe) / sigma_d), 0, 1)
R_v_i = clip(v_i^app / v_max, 0, 1)
R_t_i = exp(-TTC_i / tau_ttc)
Risk_i^now = clip(w_d R_d_i + w_v R_v_i + w_t R_t_i, 0, 1)
```

该风险作为已有 `Instant-Link-SAC` 方法和后续预测风险消融的统一基线。

### 6.3 动作条件的预测性连杆风险表征

设控制周期为 `T_c`，预测采样时刻为 `tau_k in (0,T_h]`。先将 Instant-Link-SAC 输出依次经过已有 rate limiter 和 Butterworth 滤波，得到候选名义 endpoint `q_dot_nom`。当前控制周期内按与执行器一致的 quintic `s(z)=6z^5-15z^4+10z^3` 从上一实际下发速度过渡到候选 endpoint；周期外采用“保持该 endpoint”的局部策略假设：

```text
q_dot_hat(tau; u) = q_dot_prev + s(tau/T_c)(u-q_dot_prev),  0 < tau <= T_c
q_dot_hat(tau; u) = u,                                      T_c < tau <= T_h

B(tau) = integral_0^tau s(r/T_c) dr,                         tau <= T_c
B(tau) = B(T_c) + tau-T_c,                                  tau > T_c
q_hat(tau; u) = q_t + q_dot_prev tau + B(tau)(u-q_dot_prev)
c_hat(tau) = c_t + tau v_t
```

因此任意预测时刻的机器人关节状态仍是候选终点速度 `u` 的仿射函数，同时避免假设未知的未来 SAC 动作。控制器在下一周期使用新观测滚动重规划。实际实现允许本周期使用全部 240 Hz 子步、周期外使用较稀疏采样；约束采样集合必须在 validation 冻结。

障碍物采用局部匀速近似，机器人预测则显式依赖候选动作。对每个预测时刻重新计算表面间隙 `d_hat_i(tau_k; q_dot_nom)`，定义：

```text
d_i^pred(q_dot_nom) = min_k d_hat_i(tau_k; q_dot_nom)
k_i^crit = argmin_k d_hat_i(tau_k)
T_i^enter = min {tau_k | d_hat_i(tau_k) <= d_safe}
```

若预测时域内未进入安全边界，则令 `T_i^enter = T_pred_max`。预测风险分量为：

```text
R_pred_d_i = clip(exp(-(d_i^pred - d_safe) / sigma_pred), 0, 1)
R_enter_i = exp(-T_i^enter / tau_pred)
R_horizon_i = sum_k omega_k phi(d_hat_i(tau_k)) / sum_k omega_k
omega_k = exp(-eta tau_k)
```

最终预测性连杆风险定义为：

```text
Risk_i^pred = clip(
    w_now Risk_i^now
    + w_min R_pred_d_i
    + w_enter R_enter_i
    + w_h R_horizon_i,
    0, 1
)
```

各权重非负且和为 1。主方法直接用预测间隙与首次越界时间选择 QP 约束；该复合风险只用于诊断、排序 tie-break 或可选调度，不扩展 SAC observation，也不决定硬安全边界。正式参数仅在 validation 选择，随后对 held-out 固定。

### 6.4 全身约束筛选与诊断风险聚合

硬最大值 `max_i Risk_i` 作为基线。拟采用温度可控的 Softmax 加权聚合：

```text
z_i = w_i^link Risk_i^pred
alpha_i = exp(tau_s z_i) / sum_j exp(tau_s z_j)
Risk_body = sum_i alpha_i Risk_i^pred
```

若没有充分依据，连杆权重 `w_i^link` 统一取 1。该聚合值保持在各连杆风险值的范围内；`tau_s` 越大，其行为越接近硬最大值。风险分数只用于日志、排序或可选调度，不进入安全约束本身。主方法按预测间隙、首次越界时间和当前近阈值集合直接选择约束；SAC 保持已验证的 `link_risk_v1` observation。Softmax 与 hard max 仅为次要消融，不是论文成立的必要条件。

### 6.5 SAC 名义策略

SAC 先输出策略关节速度，随后按已有执行管线得到 QP 的名义 endpoint：

```text
a_t in [-1, 1]^6
q_dot_policy = q_dot_max * a_t
q_dot_limited = rate_limit(q_dot_policy)
q_dot_nom = Butterworth(q_dot_limited)
```

`q_dot_nom` 是预测线性化参考和 QP 跟踪目标。QP 输出安全 endpoint 后只进行确定性 quintic 展开，不再经过 Butterworth 或其他滤波。

名义策略沿用已经正式复评估的当前连杆风险状态：

```text
s_t = [
    q_t, q_dot_t, e_p_t,
    D_t, N_t, V_app_t, TTC_t,
    Risk_body_now_t, closest_link_t,
    q_dot_cmd(t-1)
]
```

任务奖励保持简洁：

```text
r_task = -w_p ||p_ee - p_g||^2
r_progress = w_prog (||e_p(t-1)|| - ||e_p(t)||)
r_smooth = -w_c ||q_dot_cmd(t) - q_dot_cmd(t-1)||^2
r_success = R_s I[success]
r_t = r_task + r_progress + r_smooth + r_success
```

任务奖励和 current-risk 固定惩罚沿用 `link_fixed_penalty1`。预测 observation、raw predicted-risk reward 和 excess-risk reward 的门控实验均作为失败/敏感性消融保留，不再为追求正结果继续扩大训练；部署安全由动作条件预测 QP 独立承担。

### 6.6 动作条件、轨迹嵌入式安全 QP

安全层输入 Instant-Link-SAC 名义终点速度 `q_dot_nom`、当前机器人/障碍物状态和前一周期实际执行状态。优化变量为安全终点速度 `u` 与逐约束松弛 `xi_(i,k)`。对一个控制周期内的 `M` 个物理子步，固定 quintic 基函数 `s_k` 给出：

```text
q_dot_k(u) = q_dot_prev + s_k (u - q_dot_prev)
q_k(u) = q_t + Delta t_phys sum_(r=1)^k q_dot_r(u)
a_k(u) = [q_dot_k(u) - q_dot_(k-1)(u)] / Delta t_phys
j_k(u) = [a_k(u) - a_(k-1)(u)] / Delta t_phys
```

这些量对 `u` 均为仿射函数。以名义动作轨迹为线性化参考，对 Top-k 危险连杆和选定未来子步构造：

```text
d_hat_(i,k)(u) ~= d_ref_(i,k) + G_(i,k) (u - q_dot_nom)
d_hat_(i,k)(u) >= d_safe + m_unc - xi_(i,k)
```

`d_ref_(i,k)` 同时外推障碍物和候选机器人子步；`G_(i,k)` 是本周期固定的距离—终点速度梯度。QP 为：

```text
min_(u,xi) ||u-q_dot_nom||_W^2
            + lambda_a sum_k ||a_k(u)||^2
            + lambda_j sum_k ||j_k(u)||^2
            + sum_(i,k) rho_(i,k) xi_(i,k)^2
```

约束为：

```text
d_hat_(i,k)(u) >= d_safe + m_unc - xi_(i,k)
q_dot_min <= q_dot_k(u) <= q_dot_max
q_min <= q_k(u) <= q_max
-a_max <= a_k(u) <= a_max
-j_max <= j_k(u) <= j_max
0 <= xi_(i,k) <= xi_max
||u-q_dot_nom||_inf <= delta_u
```

活跃约束集合取“当前危险连杆、名义轨迹预测 Top-k 连杆、距阈值最近连杆”的并集，而不是只保留单一 argmax。`W/lambda/rho`、预测时刻、Top-k 和保守裕量先在 validation 冻结，主实验不使用在线变化的权重。矩阵保持半正定，约束关于 `u,xi` 为仿射，因此使用 OSQP 等标准求解器时单次在线问题是凸 QP。信赖域限制局部线性化偏差，并用 validation 上的距离残差分位数标定 `m_unc`。

约束优先级明确为：有限值与关节位置/速度/acceleration/jerk 边界最高；预测安全约束允许有界独立 slack；信赖域若与硬边界冲突可收缩或移除。求解失败、slack 超阈或监测异常时进入降级停止。停止过程可能暂时不满足正常运行 jerk 指标，必须单独报告。风险自适应权重或动态 Top-k 仅作为后续消融，不能成为主方法可行性的前提。

该方法的安全结论限定于短时运动模型、局部距离线性化、状态观测和 QP 可行等假设。软松弛、离散执行和模型误差存在时不宣称形式化无碰撞保证。

### 6.7 一致执行与子步监测

QP 的安全终点速度 `u` 唯一确定其优化时已经检查的 quintic 子步轨迹。执行器必须原样执行该轨迹，不得再附加会改变轨迹的滤波或插值：

```text
Instant-Link-SAC 名义终点速度
-> 动作条件预测与约束选择
-> 轨迹嵌入式安全 QP
-> 已约束的 quintic 子步轨迹
-> 子步监测与执行
```

子步监测不重新塑形正常动作，只检查实测/仿真间隙、跟踪误差、感知状态、求解状态和 slack。任一量超出降级阈值时进入限速或停止；降级停止不纳入正常 jerk 连续性承诺。

### 6.8 训练与部署流程

流程分为两个模块：

1. **名义策略。** 冻结已经完成正式复评估的 Instant-Link-SAC checkpoints，不再依赖预测 observation/reward 重新训练主策略。现有 checkpoints 在 EMA 执行器下训练，而安全层实验统一改用 RTB；因此主要因果结论来自“同一 actor、同一 RTB、同一 episode seed”的成对反事实，不能把绝对性能解释为训练—部署执行器完全一致的端到端结果。
2. **安全层。** 仅在 validation seeds 上选择预测时域、Top-k、裕量和固定 QP 参数，然后固定 actor 与参数进行独立 held-out 反事实评估。RTB 重新训练 actor 只作为可选鲁棒性复核，不是继续主线的前置条件；若未来研究安全层在环训练，必须作为独立扩展报告。

部署阶段不进行在线强化学习更新。每个控制周期记录名义动作、安全动作、介入原因、活跃连杆、优化状态、风险和最终执行动作，以支持可解释性和失败分析。

### 7.2 主比较与消融矩阵

| 方法 | 风险信息 | 名义策略安全处理 | 执行期指令整形 | 目的 |
| --- | --- | --- | --- | --- |
| `EE-SAC` | 末端当前风险 | 固定惩罚 | 无 | 末端风险基线 |
| `Instant-Link-SAC` | 当前连杆风险 | 固定惩罚 | 无 | 已有连杆级基线 |
| `Predictive-Link-SAC`（失败消融） | 预测风险直接进入状态/奖励 | 固定惩罚 | 无 | 说明为何预测不直接耦合策略 |
| `Instant-Link-SAC+Reactive-Projection` | 当前连杆风险 | 固定惩罚 | 现有单时刻迭代投影 | 已验证的工程基线 |
| `Instant-Link-SAC+One-Step-QP` | 当前连杆风险 | 固定 Instant-Link actor | 标准 QP、当前时刻安全约束、quintic 运动边界 | 隔离求解器与运动边界作用 |
| `Proposed: Predictive-Trajectory-QP` | 动作条件逐连杆间隙 | 固定 Instant-Link actor | 多时刻预测安全约束 + 同一 quintic 运动边界 | 验证预测约束增益 |
| `LDRC-SAC`（次要） | 当前连杆风险 | 约束 SAC | 无 | 保留已有安全处理比较 |

正式主结论最低完成 `Instant-Link-SAC+RTB`、`Reactive-Projection`、`One-Step-QP` 和 `Proposed` 四组，并使用相同固定 actors、相同 RTB 和相同 episode seeds 做配对反事实。`One-Step-QP` 与 `Proposed` 使用同一标准求解器和运动边界，唯一核心差异是当前时刻约束与动作条件多时刻间隙约束。`Predictive-Link-SAC` 保留为有边界的负结果；EMA 下的 `EE-SAC` 与 `LDRC-SAC` 只作背景结果，不与 RTB 安全层变体进行直接因果排序。

### 7.3 已有结果与其用途

旧三方法 held-out 表存在 episode seed 重叠，只保留作历史记录。修复后的独立-seed 正式复评估包含 13,500 个无重复实验单元；五场景宏平均中，`link_fixed_penalty1` 的成功率为 61.33%，碰撞率为 6.80%，均优于本轮 `ee_fixed` 和 `ldrc_fixed`，确认其适合作为新方法起点。该结果仍不能用于证明预测风险或安全 QP 指令整形器。

按现有控制周期采样口径，固定 actor 五场景反事实已验证反应式投影器的即时作用：相对 RTB baseline，宏平均碰撞率由 6.91% 降至 1.49%，安全违反率由 1.519% 降至 0.238%，成功率由 61.67% 升至 63.71%，子步命令 RMS jerk 未增加。P5 endpoint/quintic 管线进一步验证了 `12/500` 命令峰值边界，但其安全约束未覆盖所有子步，也未使用关节反馈计算真实运动导数，因此只作为过渡消融。Predictive-Link-SAC 的 30k、100k 和 reward-shaping 门控均未取得任务与安全共同收益，作为模块化设计选择的负证据保留。

### 7.4 评价指标

| 类别 | 指标 | 作用 |
| --- | --- | --- |
| 任务性能 | Success Rate、Final Position Error、Completion Time | 衡量到达能力与效率 |
| 结果安全 | Collision Rate、Non-End-Link Collision Rate、Minimum Distance、Safety Violation Rate | 衡量最终安全结果 |
| 预测能力 | Warning Lead Time、未来最小距离误差、风险连杆识别率 | 衡量是否提前且正确发现危险 |
| 干预行为 | Intervention Rate、Intervention Duration、Action Correction Norm、Active/Slack Constraints、Solver Status | 衡量指令整形器是否克制和可行 |
| 平滑性 | 命令与反馈分别统计 RMS/Peak Joint Acceleration、RMS/Peak Jerk、Motion-Limit Violation Rate | 区分下发命令约束与机器人实际跟踪 |
| 实时性 | Policy Inference Time、Risk Prediction Time、QP Solve Time、Cycle Overrun Rate | 衡量部署可行性 |

首次预警提前量定义为：

```text
LeadTime = t_first_violation_or_collision - t_first_warning
```

若 episode 未发生越界，可根据障碍物轨迹的反事实最近时刻或预设穿越时刻统计，必须在论文中统一口径。动作修正幅度定义为：

```text
CorrectionNorm = ||q_dot_cmd - q_dot_nom||_2
```

仅报告低碰撞率不足以证明指令整形器有效，还需同时报告介入率和修正幅度，避免方法通过长时间停止获得表面安全。

### 7.5 核心实验一：预测与动作条件有效性

固定 Instant-Link-SAC 动作，在相同离线/在线轨迹上比较当前风险、当前运动趋势预测与候选动作条件预测；Predictive-Link-SAC 只作为失败消融，不承担核心正结论。

场景包括：

- 障碍物以不同速度侧向穿越上臂、肘部、前臂和腕部；
- 当前距离相同但接近速度不同；
- 当前距离较近但正在远离；
- 障碍物发生一次速度突变。

主要回答：预测风险能否增加预警提前量，候选动作条件预测能否提高未来间隙/危险连杆判断准确度，以及这些改进能否转化为更早且更少的 QP 干预。

### 7.6 核心实验二：预测轨迹嵌入式安全 QP 有效性

在相同固定 Instant-Link-SAC actors 上成对比较无安全层、现有 Reactive-Projection、标准 One-Step-QP 与 Proposed。除任务和碰撞指标外，重点报告：

- 指令整形器介入次数与持续时间；
- 每次介入的活跃连杆和动作修正幅度；
- 加速度、jerk 的均方根值、峰值及运动约束活跃率；
- 标准 QP solver status、slack、求解时间、超时和停止次数；历史投影器另报迭代后残差失败率；
- 启用指令整形器后成功率或完成时间的变化。

该实验的理想结论不是“指令整形器从不介入”，而是“在少量高风险时刻进行有限修正，显著降低碰撞与安全距离违反，同时保持可接受的任务完成能力”。

### 7.7 核心实验三：风险聚合与预测时域消融

| 消融因素 | 候选设置 |
| --- | --- |
| 预测时域 `H Delta t_p` | 短、中、长三个时域 |
| 预测模型 | 当前反应式；当前速度外推；候选动作条件外推 |
| 全身聚合 | hard max；Softmax 加权聚合 |
| 活跃约束数量 | Top-1；Top-2；所有预警连杆 |
| 轨迹约束覆盖 | 仅 endpoint；全部下发子步命令并逐子步反馈监测 |
| 加速度与 jerk 机制 | 无连续性项；仅硬边界；软代价 + 硬边界 |
| 连续性权重 | 固定权重为主；风险自适应权重仅作可选消融 |

分析安全性、任务效率、误报、jerk 和计算开销之间的变化。参数选择应基于验证集综合指标，不在最终测试集上反复选择。

### 7.8 鲁棒性与泛化实验

鲁棒性实验优先覆盖现实中最可能破坏预测模型的因素：

| 因素 | 设置 |
| --- | --- |
| 位置噪声 | 对障碍物位置加入分级高斯噪声 |
| 速度误差 | 速度缩放、方向扰动和估计延迟 |
| 运动突变 | 障碍物中途改变速度或方向 |
| 控制延迟 | 增加 1 至若干控制周期延迟 |
| 未见速度 | 测试速度范围略超出训练分布 |

多障碍物只作为附加泛化：使用两个球形障碍物验证风险计算和 QP 约束能否自然扩展，不以此作为主要创新结论。

### 7.9 安全与平滑统一指令整形消融

在相同 actor、RTB 和测试轨迹下比较：原始 SAC 动作、现有 Reactive-Projection、标准 One-Step-QP，以及动作条件 Predictive-Trajectory-QP。重点分析标准求解器、运动命令边界和未来间隙约束各自对碰撞率、成功率、动作修正幅度、峰值 jerk、slack 与求解时间的影响。

现有 actor 在 EMA 下训练，而本组安全层实验统一使用 RTB，因此公平性来自同 actor、同 RTB、同 episode 的成对反事实；论文明确披露该执行器迁移，不声称训练—部署完全同分布。若补做 RTB actor 重训，只作为外部有效性复核。历史滤波系数自适应结果只用于说明方案选择过程；风险自适应 QP 权重不是核心方法。

### 7.10 真实 UR5 低速验证

真实实验使用单台 RGB-D 相机检测轻质球形障碍物，位置经外参转换到机器人基坐标系，速度由连续帧差分和低通滤波估计。机械臂采用限速、工作空间限制、感知丢失停止和人工急停。

建议至少完成以下两组，每组 10 至 20 次：

1. `Instant-Link-SAC`：冻结名义策略，保持保守速度上限。
2. `Proposed`：相同策略启用动作条件、轨迹嵌入式安全 QP。

真实实验不故意制造接触，使用安全距离违反、最小距离、介入率、动作修正幅度、任务成功率和执行稳定性进行比较。展示平台照片、关键帧序列、`d_min`、预测风险、活跃连杆、名义/修正速度和求解耗时曲线。

真实实验只支持低速部署可行性和基本风险响应结论，不替代受控仿真消融，也不作为绝对安全证明。

### 7.11 失败案例与适用边界

| 失败场景 | 可能原因 | 应记录信息 |
| --- | --- | --- |
| 障碍物速度过快 | 机械臂速度与预测提前量不足 | `d_pred`、LeadTime、速度限幅、停止时刻 |
| 障碍物突然转向 | 匀速模型失配 | 速度估计、预测误差、风险变化率 |
| 目标与避障方向冲突 | 安全约束压缩可行动作空间 | QP 活跃约束、松弛量、最终误差 |
| QP 频繁介入 | 风险阈值过低或名义策略依赖安全层 | Intervention Rate、CorrectionNorm |
| 标准 QP 失败或高 slack | 多约束冲突、线性化失效或已进入危险区域 | solver status、primal/dual residual、slack、最小距离、降级状态 |
| 最近点/连杆切换 | 几何近似引起风险不连续 | 最近点、Top-k 连杆、hard/soft 聚合结果 |
| 感知丢失或延迟 | 真实观测不可用 | 检测状态、时间戳、停止延迟 |

本文结论限定为：在主要连杆几何模型可用、动态球形障碍物状态可观测、短时局部线性化有效、QP 可行且执行器跟踪误差受监测的条件下，动作条件全身预测与轨迹嵌入式安全 QP 能否改善机械臂静态目标到达过程中的提前预警、整臂避障和平滑执行表现。

## 九、实施优先级与完成判据

为避免范围失控，后续工作按以下顺序开展：

1. 已完成有限时域连杆距离预测、离线预警验证和预测 observation schema。
2. 已完成固定 `Instant-Link-SAC` actor 的 Reactive-Projection 独立-seed 五场景反事实，确认当前约束方向和低开销介入具有工程效果；历史名称 `minimal_qp` 不代表标准 QP。
3. 已完成 endpoint/quintic 加速度与 jerk 边界反事实；该结果作为过渡消融，不等同于最终轨迹嵌入式安全约束。
4. 停止继续扩大未过门控的 Predictive-Link-SAC；先修复逐物理子步状态/距离/接触监测和指标命名，再实现候选动作条件预测、距离线性化与 OSQP 标准求解器。
5. 依次完成 Reactive-Projection、One-Step-QP、Predictive-Trajectory-QP 的 validation；固定预测时域、Top-k、裕量和 QP 参数后再运行独立 held-out seeds。风险自适应调度不作为必做项。
6. 完成噪声、延迟和速度突变鲁棒性实验；真实 UR5 只在硬件接口与现场安全签核具备时开展，不作为仿真主结论成立的前提。

论文核心方法达到可写结论的最低判据为：

- 候选动作条件预测相较当前运动趋势预测具有可重复的间隙/危险连杆预测收益，并保持可解释的误报率；
- 完整方法相较无安全 QP 指令整形的方法降低碰撞率或安全距离违反率，且成功率没有不可接受下降；
- 完整方法相较无运动边界版本降低命令 Peak jerk，全部下发子步命令满足配置边界，并报告关节反馈的跟踪误差和边界违反；
- 标准 QP 求解耗时满足控制周期要求，solver failure、高 slack、cycle overrun 和长期停止率可解释；
- 至少 3 个训练随机种子和独立测试种子得到方向一致的结果；
- 所有创新结论均有对应消融，未完成模块不写成既成贡献。
- QP 必须使用真正的凸优化求解并报告状态、slack、迭代/求解耗时；当前迭代半空间投影仅作 P4 工程基线。

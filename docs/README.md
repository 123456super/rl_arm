# 文档导航

研究题目：**面向障碍布局变化的机械臂强化学习避障方法研究**。

统一任务定义：**目标位置随机、目标姿态相对于机器人基座固定。**绕障过程中允许改变末端姿态，最终恢复规定朝向；S0/S1/S2 保持同一任务约定。保留位置 0.01 m、姿态 0.10 rad、连续保持 5 步的成功要求，不锁定腕部关节。主配置复用 `reference_ppo` 的目标欧拉角 `[0, 1.57, 1.57]` rad 和位置提议，但关键点模式改用 `[45, -90, 90, 0, 45, -90]` 度的弯曲准备构型，并增加可达性及目标碰撞检查。参考模式仍保留零初态，详见训练与实验说明。

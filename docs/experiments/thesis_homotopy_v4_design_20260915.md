# S0 位置优先位姿课程（v4）

> **已终止（2026-09-16）**：旧协议历史记录，仅用于失败追溯；不续训、不参与 v8 模型选择。

日期：2026-09-15  
协议：`position_first_pose_then_safety_homotopy_v4`

## 修改原因

v3 正式 S0 训练 100000 transition 后仍停留在 `goal_scale=0.03`，滑窗成功率约为 0.12。replay 中约 65.38% 的 episode 曾满足位置容差，但只有约 17.75% 同时满足 `0.10 rad` 姿态容差。局部位置能力已经出现，但位置与姿态从训练开始就共同控制成功终止，使目标范围课程无法启动。

## 两级任务课程

S0-P 固定姿态任务系数 `eta=0`。成功只要求位置误差不超过 `0.055 m`，目标范围系数 `g` 由 `0.03` 在成功率门控下增加至 `1`。达到完整目标范围后继续训练至少 25000 transition。

S0-R 仅在上述巩固完成后开始，并固定 `g=1`。`eta` 在当前任务成功率达到 0.80 时按 transition 从 0 增至 1；姿态容差同步按 `theta(eta)=pi+eta(0.10-pi)` 收紧。`eta=1` 后再训练至少 25000 个完整位姿 transition。S0 Gate 的前置条件为：

```text
g=1, eta=1, K_position>=25000, K_pose>=25000
```

validation、S1 和 S2 固定使用 `g=1, eta=1`。S1/S2 的安全系数 `xi` 调度不变，因此任务同伦在安全同伦之前完成，两者不冲突。

## 输入与奖励

observation 由 69 维扩展为 70 维，新增归一化后的 `eta`。这是必要的，因为 `eta` 会改变姿态奖励及终止条件；若不输入网络，旧、新 replay 会形成相同物理观测对应不同任务定义的隐状态。

位置进展权重保持 18，姿态进展权重为 `4 eta`，成功奖励保持 20。新增四个有界正则：位置状态最多 0.03、姿态状态最多 `0.02 eta`、速度幅值最多 0.04、速度变化最多 0.01，单步总和不超过 0.10。100 个可达目标预检中，理想到达、静止超时、严格立即碰撞/硬失败的中位折扣回报约为 `21.98、-3.26、-10.04`，期望排序通过率为 100%。

- 全量测试：72 passed。
- 300-step 训练冒烟：293 次更新，reward 范围 `[-0.547,20.135]`，正奖励比例 42.67%，70 维完整 checkpoint 保存成功。

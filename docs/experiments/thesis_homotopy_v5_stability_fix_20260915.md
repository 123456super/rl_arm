# S0 v5 课程与价值稳定性修正

> **已终止（2026-09-16）**：旧协议历史记录，仅用于失败追溯；不续训、不参与 v8 模型选择。

日期：2026-09-15  
协议：`position_first_pose_then_safety_homotopy_v5`

## v4 失败诊断

v4 的前 10k transition 位置成功率为 81.8%，证明位置优先终止能够建立简单目标到达能力。但课程滑窗保留了更小 `g` 的历史成功，导致策略尚未在新尺度稳定时继续换挡；最终冻结在 `g=0.1259912`。末 10k 的成功率、自碰撞率和超时率分别约为 2.0%、40.8% 和 53.1%。

同时，训练 Q 均值从 10k 的约 21.5 上升至 100k 的约 106.8；末 10k 日志轨迹的有限时域实际折扣回报中位数为 -5.82、p95 为 1.58。最新 replay 状态上的 critic Q 中位数约为 100，属于明确的 bootstrap 高估。最终 actor 的确定性动作绝对值均值为 0.679，32.3% 的动作分量超过 0.9。

## v5 修正

1. 目标尺度改为 16 个固定台阶：`0.03, 0.04, 0.05, 0.065, 0.08, 0.10, 0.125, 0.16, 0.20, 0.25, 0.32, 0.40, 0.50, 0.65, 0.82, 1.0`。
2. 每个台阶至少采集 5000 个有效 transition，并在该固定尺度独立取得最近 100 个 episode 的位置成功率不低于 0.80；换挡后窗口及台阶计数归零。
3. 前 3000 步随机 warm-up transition 不计入课程台阶步数；包含随机动作的 episode 不进入课程成功窗口。
4. observation 新增剩余时域，从 70 维变为 71 维；timeout 以 replay `done=1` 处理，阻断跨越有限时域边界的 bootstrap。
5. critic 学习率从 `3e-4` 降至 `1e-4`，MSE 改为 Huber loss，联合梯度范数裁剪到 10。
6. actor 与温度每两个 critic update 更新一次，actor 梯度范数裁剪到 10。
7. checkpoint 新增 SAC 内部 update 计数和最近 actor 指标，保证延迟更新相位能够精确恢复。

姿态课程及后续安全同伦的目标没有改变：只有位置课程达到 `g=1` 并巩固 25k transition 后才启动 `eta`；S1/S2 仍在完整位姿任务上调度安全系数 `xi`。

## 实现验证

- 针对性测试：15 passed。
- 全量测试：73 passed。
- 400-step 训练冒烟成功，71 维完整 checkpoint 可保存。
- 从活动 episode checkpoint 继续 100 transition 成功；replay 从 400 增至 500，SAC update 从 393 增至 493。
- 冒烟全部处于 warm-up，课程保持 `g=0.03`、台阶有效计数为 0，符合隔离规则。

v4 checkpoint 与 v5 的网络输入、课程状态、timeout 语义和优化器更新相位均不兼容，正式训练必须从零开始。

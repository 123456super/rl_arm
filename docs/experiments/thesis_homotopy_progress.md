## 当前状态

v3 的 S0 seed 11001 已完成 100000 transition，但课程始终停留在 `goal_scale=0.03`，末尾位置/位姿任务滑窗成功率仅约 `0.12`，未取得 Gate 资格。replay 诊断显示约 `65.38%` 的 episode 曾进入位置容差，但只有约 `17.75%` 同时进入原 `0.10 rad` 姿态容差；说明“位置和姿态从第一步同时作为硬成功条件”阻断了局部目标课程。v3 checkpoint 不再继续训练，保留为失败诊断依据。

v4 的 100k S0 首先证明位置优先能够在最简单目标上建立能力：前 10k episode 成功率约 81.8%。但课程窗口混入旧尺度成功，`g` 在约 4948 个合格 transition 内推进到 0.126 后崩塌，末 10k 成功率约 2.0%。同时 Q 均值从约 21.5 持续上升到 106.8，而末 10k 实际折扣回报中位数仅为 -5.82，确认存在严重 bootstrap 高估。因此 v4 不继续训练或进入 Gate。

v2～v4 分别使用 55、69、70 维网络；v5 使用 71 维网络及新的课程/优化器状态。训练器和评价器会按 protocol 拒绝跨版本恢复，因此 v5 S0 必须从随机初始化开始。

v5 seed 11001 的 block1 成功把目标范围推进到 `g=1`，累计 `21725/25000` 个完整范围位置巩固 transition；`g=1` 训练成功率为 `99.78%`，50 个固定目标的确定性位置复测为 `100%`。block2 在约 3.3k transition 后进入姿态课程，100k 结束时推进到 `eta=0.71878`、容差 `0.955 rad`，但末窗任务成功率只有 `0.77`。最终策略在 50 个固定目标上当前难度成功率为 `68%`，纯位置复测降至 `74%`、自碰撞率升至 `16%`，说明连续姿态课程和 60k FIFO replay 淘汰早期位置数据后发生到达能力遗忘。v5 block2 不再继续。

v6 从 v5 block1 的纯位置完整 checkpoint 显式迁移 actor、critic、target、优化器、温度、replay 和 RNG，不继承失败的连续姿态课程状态。姿态改为离散课程，并加入位置锚点混训、双能力门控和姿态分层 replay。

v6 seed 11001 姿态 block1 已完成 100000 transition，姿态课程推进到 `eta=0.6`、容差 `1.317 rad`，末窗姿态成功率 `0.86`、训练位置锚点率 `0.9579`。姿态能力真实改善：`eta=0.6` 训练 episode 的平均姿态误差由约 `2.208 rad` 降至 `1.232 rad`。但同一组 50 个固定位置目标的确定性成功率从 25k checkpoint 的 `100%` 依次降至 50k 的 `98%`、75k 的 `94%` 和 100k 的 `88%`，并在 100k 出现 `8%` 自碰撞与 `4%` 关节越界。v6 减缓但没有消除共享 actor 的位置遗忘，因此不从 100k checkpoint 继续。

v7 从 v6 的 25k checkpoint（`eta=0.2`，固定位置复测 `50/50`）迁移完整 SAC、replay 和 RNG。迁移时保留已学网络与可重算原子奖励的 replay，但清空当前 `eta=0.2` 的 transition 计数、姿态窗口、锚点窗口和活动 episode，要求在 v7 奖励契约下重新取得资格。v7 不使用永久专家池或旧 actor 蒸馏：姿态奖励根据可观测位置误差从远区的 20% 平滑提升至近区的 100%；位置保持率下降时，当前策略生成的位置锚点 episode 概率及 replay 比例动态提高；每次姿态晋级还必须通过独立固定种子的确定性位置探针。

## 当前有效实现

- 71 维 observation 在 v4 基础上显式加入剩余时域；timeout transition 以 `done=1` 写入 replay，停止跨越有限时域边界的 bootstrap。
- 动作为 20 Hz 原始关节速度命令，每个控制周期执行 12 个 240 Hz 物理子步。
- S0-P 固定 `eta=0`，按 16 个离散 `g` 台阶训练；每个台阶至少 5000 个非 warm-up transition，并使用独立的 100-episode 窗口。换挡后窗口清零，warm-up 不得推进课程。
- S0-R 固定 `g=1`，按 17 个离散档位将 `eta` 从 0 增至 1，同时把姿态容差从 `pi` 收紧到 `0.10 rad`。每档至少 5000 个当前任务 transition；换档后姿态和位置锚点窗口均清零，分别达到 `0.80/0.95` 才能继续。
- `eta>0` 后以 25% episode 概率训练 `eta=0` 位置锚点；S0 batch 按位置锚点/当前姿态/历史姿态 `25%/50%/25%` 抽取，历史部分按已有姿态档位均衡采样。
- v7 正常/中间/恢复模式的锚点 episode 概率为 `0.25/0.40/0.50`；replay 比例分别为 `25/50/25`、`40/40/20`、`50/35/15`。锚点率低于 `0.98` 进入中间模式，低于 `0.95` 或确定性探针失败进入恢复模式并冻结姿态晋级。
- 姿态进展和姿态状态项乘以位置距离门：位置误差不小于 `0.20 m` 时使用当前 `eta` 的 20%，在 `0.20 m` 到 `0.08 m` 之间用 smoothstep 增强，小于等于 `0.08 m` 时使用完整 `eta`；姿态成功容差仍只由离散 `eta` 决定。
- 每次准备换姿态档时运行 50 个私有课程探针目标；确定性位置成功率至少 `0.95`，且碰撞率和关节越界率均为 0 才允许晋级。该探针不使用 held-out。
- 目标仍由候选关节构型 FK 生成，并通过带姿态 IK、关节限位、自碰撞和 FK 回代误差检查。
- 宽容期任务球碰撞不终止，安全惩罚从 `xi=0.02` 起步，到达奖励始终保持不变。
- 位置进展项始终启用，姿态进展项按 `eta` 加入；位置状态、姿态状态、速度幅值和速度变化正则的单步总上界为 `0.10`，成功奖励为 20。
- 安全边界穿入量连续裁剪到 `[0,1]`，风险裁剪到 `[0,1]`；安全项只由这两个连续量构成且上界为 10，硬失败惩罚固定为 10，不再使用按状态成本放大的吸收态惩罚。
- replay 保存奖励原子量并按当前 `xi` 重算；进入严格期后保留首次 contact、改为 terminal、删除碰撞后 transition，并对首次 contact 重算有界碰撞惩罚。
- S0/S1/S2 继承完整 actor、critic、target、optimizer、温度、replay、课程状态和 RNG；禁止只加载 actor。
- 根 seed 派生独立的环境、课程、replay、warm-up action 和网络 RNG 流；活动 episode 的关节状态按 PyBullet 双精度保存。
- critic 学习率降为 `1e-4`，改用 Huber loss 和梯度裁剪；actor/alpha 每两个 critic update 更新一次，actor 同样执行梯度裁剪。
- 严格评价 Gate 使用任务球、自碰撞和环境碰撞的总碰撞率，并报告位姿误差 mean/p95 与最小间隙。
